常见问题

你可能想问

为什么挂载时需要输入管理员密码？＋

以读写方式重新挂载磁盘卷需要系统级授权，这是 macOS 的安全机制，与 Paragon 等商业软件一致。密码只用于本次挂载，不会被保存或上传。

支持哪些设备？会动到我的数据吗？＋

支持 NTFS 格式的 U 盘、移动硬盘与硬盘盒（APFS / FAT32 / exFAT 由 macOS 原生处理，无需本工具）。工具只负责挂载流程，不读取、不改动磁盘里的任何数据。

首次访问磁盘提示「不允许访问」怎么办？＋

打开 系统设置 → 隐私与安全性 → 文件和文件夹 → 网络卷，为相关访问打勾即可。这是挂载通道的一次性授权，之后不会再弹。

中文文件名会乱码吗？和 Windows 互通吗？＋

不会。引擎原生支持 Unicode，中文、日文文件名与 Windows 下的 NTFS 完全互通，在 Mac 上写的内容插回 PC 照样正常打开。

真的完全免费？＋

是。本工具个人使用完全免费，底层 ntfs-3g 与 FUSE-T 均为开源项目。仍建议重要数据定期备份——好习惯比任何软件都可靠。
